# Додаток 2. Структурна схема даних (Нотація Crow's Foot)

У цій структурі відображені реальні фізичні таблиці бази даних нашого розумного тренажера правопису, типи полів, первинні (`PK`) та зовнішні (`FK`) ключі, а також зв'язки «Один-до-Багатьох» (1:M) після нормалізації зв'язку багато-до-багатьох для досягнень.

```mermaid
erDiagram
    users ||--o{ scores : "проходить (1:M)"
    users ||--o{ user_achievements : "отримує (1:M)"
    users ||--o{ user_mistakes : "робить (1:M)"
    games ||--o{ scores : "має записи (1:M)"
    games ||--o{ questions : "має завдання (1:M)"
    subjects ||--o{ games : "містить (1:M)"
    achievements ||--o{ user_achievements : "присвоюється (1:M)"

    users {
        int id PK
        varchar username
        varchar password
        varchar role
        timestamp created_at
    }
    subjects {
        int id PK
        varchar name
        text description
    }
    games {
        int id PK
        int subject_id FK
        varchar name
        text description
    }
    questions {
        int id PK
        int game_id FK
        text question_text
        varchar correct_answer
        int sort_order
    }
    scores {
        int id PK
        int user_id FK
        int game_id FK
        int score
        int correct_answers
        int total_questions
        timestamp played_at
    }
    achievements {
        int id PK
        varchar name
        varchar description
        varchar badge_path
        varchar system_key
    }
    user_achievements {
        int user_id PK,FK
        int achievement_id PK,FK
        timestamp earned_at
    }
    user_mistakes {
        int id PK
        int user_id FK
        text question_text
        varchar correct_answer
    }
```
